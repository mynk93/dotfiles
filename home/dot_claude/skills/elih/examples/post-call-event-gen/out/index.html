Decisions and choices

IdChunkSummaryStateBy
D-31Field guideNo Bifrost extractor in the first release. Tenant definitions are hand-written modules loaded from Git at one pinned commit
Editor's note (ADR)Bifrost could generate tenant definitions from the legacy detector's config, but the output would have to be reviewed line by line anyway and would tie the first release to Bifrost's schema. Hand-written modules pinned to one Git commit are slower to author and trivial to audit; the extractor can be added later without changing the loader.
approvedyou, 2026-09-24
D-32Loading dockThe first shadow milestone runs in prod, not dev. Dev is a smoke stage only
Editor's note (ADR)Dev has no real call traffic, so a shadow there compares the sorter against nothing. Prod shadow is safe because P1 holds (shadow writes reach no customer surface) and it produces the only data that can promote a tenant. The cost is that the first worker deploy is a prod deploy, which is why the loading dock has its own review order.
approvedyou, 2026-10-05
D-33Sorting deskThe worker does not use the legacy detector at all. No LLM pass, no transcript or voicemail extractorsapprovedyou, 2026-10-06 ("we want to drop the old detector")
D-34Sorting deskA proAgent-owned ambient source emits deterministic events from call metadata for every tenant (call_answered, no_answer, short_call, ...)approvedyou, 2026-10-06
D-35Field guideIn shadow, CAM's ported module runs for every served proAgent tenant that has no module of its ownrecommendedagent, 2026-10-06. Never explicitly ratified. Its value is doubtful - most CAM events are CAM-specific (agent names, agency names)
D-36The SwitchPromotion is per tenant and decided once per call in end_call. SHADOW_MODE and POST_CALL_LEGACY_DETECTION_TENANTS retired
Editor's note (ADR)A global SHADOW_MODE flag would have been one switch for every tenant, so a single bad tenant would block promotion for all. Deciding per tenant, once per call, in end_call keeps the decision next to the stamp and lets the legacy detector retire one tenant at a time. The two env lists are replaced by one tenant-keyed setting.
approvedyou, 2026-10-07 ("the PR needs to have both right now, and a clear, tested way to deprecate the old system")

Metaphor

Post office. A call ending is a letter being posted. end_call stamps it, a conveyor carries it, a sorting desk reads it against a field guide, a scorecard checks the sorter against the old clerk, and one switch decides whose sort the customer receives.
